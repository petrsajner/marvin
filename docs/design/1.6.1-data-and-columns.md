# Marvin 1.6.1: installed data and sidebar corrections

## Cause and recovery

The 1.6.0 desktop launcher identified any Gradio-compatible /config response as its own server. A development server on port 7860 was therefore reused by the installed application, showing development test chats instead of the installation's data. No incompatible chat format or deletion was found.

The installed data remains under C:/Users/Petr/AppData/Local/QwenHarness: 12 conversations, 6 registered projects, 18 available skills, global/mode/project memories. The new API was started against that directory on port 7861 without copying or merging development data. Verified through /config, /api/state and selected conversation /detail.

The API now reports its resolved data root. The launcher only reuses a matching installation, including an existing server on an alternate port. Unidentified older servers are not reused. The explicit --data-dir option supports running new source code with existing installation data in place; frontend assets and manuals come from the running code.

## UI

- Default columns 50 percent wider (330/427.5 pixels on ordinary desktop, 360/480 on wide desktop), constrained on small displays.
- Both inside edges draggable, keyboard arrows supported; double-click or Home resets one column. Reload/start restores defaults; widths are not persisted.
- Initially 20 conversations per selected project/search; show another 20 or collapse to recent only.
- Conversation buttons no longer flex-shrink below their multiline content.

## Verification

- Regression tests cover installation identity, alternate-port reuse and old-format chats/projects/memory/skills read without rewriting conversation files.
- Browser scenario tests/workspace_columns.browser.js checks both drag handles, reset/reload, 20/26 conversation expansion, multiline bounds and 1920/1366/1024/720/390 pixel viewports.
- Release pipeline rebuilds both manuals, tests, frontend, native launcher and installer 1.6.1.
- Original installation data was not converted, overwritten or merged with the development database. Installer is provided separately; not run over the owner's installation during verification.
